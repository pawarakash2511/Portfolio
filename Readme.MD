## ⚙️ Setup Instructions

### 1. Create the GitHub repo

```bash
# On GitHub — create a new public repo named: portfolio
# Then clone it locally
git clone https://github.com/pawarakash2511/portfolio.git
cd portfolio
```

### 2. Add files & push

```bash
# Copy index.html and README.md into the folder
git add .
git commit -m "Initial portfolio deploy"
git push origin main
```

### 3. Enable GitHub Pages

1. Go to your repo on GitHub
2. Click **Settings** → **Pages**
3. Under **Source**, select **GitHub Actions**
4. Save

### 4. Done ✅

Your site will be live at:
```
https://pawarakash2511.github.io/portfolio
```

Every push to `main` auto-deploys via the workflow.
